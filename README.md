# Auditoría estática de un módulo JavaScript

## Descripción
Proyecto académico de Verificación y Validación de Software,
Unidad 1: Evaluación Estática.

El objetivo es identificar ambigüedades en los requisitos,
inspeccionar el código JavaScript y detectar defectos
antes de realizar pruebas funcionales.

## Estructura
- src/: código fuente del módulo de descuentos.
- docs/: requisitos, checklist y documentos de revisión.
- evidencias/: registros del análisis estático.

## Estado
- Fase A: documentación preparada.
- Fase B: preparación inicial del entorno.
- Fases C y D: pendientes.

## Herramientas
- Visual Studio Code
- Node.js
- npm
- ESLint (pendiente de configuración)
